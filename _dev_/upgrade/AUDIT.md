**Version.** Rows 1, 5, 8, 9 and 10 need an app change, so the release is a major: **4.0.0**.

**For the core.** Row 10 is the core's: no lookup reaches a translation 0.6.5 stored for a moved block, including `attr-original-15`, whose id did not move but whose route did. CID-3's candidates and CID-4's check are built for the pre-0.6 shapes. Extending the lookup-only fallback to 0.6.5's tokenization and one-token routing (candidate ids from the 0.6.5 tokens, CID-4 checked against those tokens, and a phrase lookup for a host 0.6.5 routed as a phrase) would let a 3.6.17 app keep rendering every translation it has. The binding cannot do it without reimplementing the tokenizer.

**VAR-4.** `dependencies.langsys-js-typescript` becomes `^0.7.0` once the core's v0.7.0 tag exists (a 0.x caret is `>=0.7.0 <0.8.0`, so 0.6.x apps never pull it by themselves).
